## Technical Decisions

### 1. FloodTool Modes
- **polygon**: User draws area, water fills to specified level
- **tileset**: Load pre-generated 3D Tiles water surface
- **terrain**: Simple terrain-based flood fill

Chose polygon mode as default for flexibility.

### 2. TilesetService Design
- Singleton per viewer instance
- ID-based tracking for loaded tilesets
- Support both local URLs and Ion asset IDs

### 3. Type System Extension
- Added `AnalysisToolType = 'volume' | 'flood' | 'profile' | 'measure3d'`
- Created `GISToolType = Exclude<DrawToolType, null> | AnalysisToolType`
- Maintains type safety across tool system
