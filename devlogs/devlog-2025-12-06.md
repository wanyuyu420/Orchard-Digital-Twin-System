#### T16.2: Undo Function
- Implemented `undo()` function in gis.ts
- Restores `beforeState` based on action type:
  - `add`: Removes feature and destroys graphic
  - `remove`: Restores feature from snapshot
  - `update/move/style`: Applies beforeState to feature
- Moves historyIndex backward

#### T16.3: Redo Function
- Implemented `redo()` function in gis.ts
- Applies `afterState` based on action type
- Reverse of undo operations
- Moves historyIndex forward

#### T16.4: Keyboard Shortcuts

- Added `Ctrl+Y` / `Ctrl+Shift+Z` handler for redo
- Implemented `refreshGraphicsFromFeatures()` to sync graphics after undo/redo
