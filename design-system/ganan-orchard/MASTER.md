# 赣南脐橙果园数字孪生 · 设计系统基线（MASTER）

> 全局唯一事实来源。页面级覆盖见 `pages/`（不存在时以本文件为准）。
> 技术栈：Vue3 + TypeScript + CesiumJS + Element Plus + ECharts。展示端为大屏/桌面横屏。

---

## 一、视觉方向

- **风格**：深色科技大屏（Data-Dense Dashboard 深色变体）+ 克制 HUD 元素。
  - 以数据密集型仪表盘为基底：多图表、KPI 卡、紧凑栅格、低间距（density 8/10）。
  - 引入 HUD 的**少量**特征：1px 细线、透明玻璃面板、关键数字微光、角标装饰——**只用于氛围，不做主体**。
  - 不采用全屏 Neon、扫描线、闪屏等重科幻元素（阅读负担 + 性能成本高）。
- **品牌**：主强调色取「脐橙橙」，传达赣南脐橙品类；次级技术色取青色用于三维场景/GIS 元素。
- **模式**：仅深色。大屏场景不提供浅色模式；避免纯黑，用深蓝黑 #020617 打底。

## 二、色彩系统

### 2.1 中性色（底板）

| Token | 值 | 用途 |
|---|---|---|
| `--bg-base` | `#020617` | 全局底色（最底层） |
| `--bg-card` | `#0E1223` | 面板/卡片底 |
| `--bg-elevated` | `#1A1E2F` | 悬浮层、下拉、tooltip |
| `--border-subtle` | `#1E293B` | 细分隔线 |
| `--border` | `#334155` | 常规边框（1px） |
| `--text-primary` | `#F8FAFC` | 主文本 |
| `--text-secondary` | `#CBD5E1` | 次文本 |
| `--text-muted` | `#94A3B8` | 弱化文本/占位（#94A3B8 在卡片底上 ≥7:1） |

### 2.2 强调与语义色

| Token | 值 | 用途 | 深底对比 |
|---|---|---|---|
| `--accent` | `#F97316` | 品牌橙：CTA、激活态、logo、选中描边 | ≥5:1 ✓ |
| `--on-accent` | `#0F172A` | 橙底上的文字（白字在橙上仅 ~2.9:1，禁用） | ≥6:1 ✓ |
| `--tech` | `#22D3EE` | 科技青：三维选中框、坐标/连线、次级技术元素 | ≥6:1 ✓ |
| `--health-ok` | `#22C55E` | 健康 / 施肥轻度 | ≥6:1 ✓ |
| `--health-warn` | `#F59E0B` | 预警 / 施肥中度 | ≥5:1 ✓ |
| `--health-crit` | `#EF4444` | 严重 / 施肥重度 / 破坏性操作 | ≥5:1 ✓ |
| `--info` | `#38BDF8` | 中性信息提示 | ≥6:1 ✓ |

### 2.3 语义映射（业务固定，勿改）

- 健康状态：`healthy`→绿 / `warning`→琥珀 / `critical`→红（**必须色点 + 文字标签并用**，不单靠颜色）。
- 施肥等级：1 轻→绿 / 2 中→琥珀 / 3 重→红；0 未计算→灰（`--text-muted`）。
- 生长指数连续色带：绿 `#22C55E` → 琥珀 `#F59E0B` → 红 `#EF4444`（三段，与健康/施肥口径一致）。

### 2.4 对比度铁律

- 正文 ≥ 4.5:1，大字/图表标记 ≥ 3:1。
- 橙色 `#F97316` 上永远用深色文字 `#0F172A`，不用白色。
- 灰底上禁用灰字（如 `#94A3B8` 上放 `#64748B`）。

## 三、字体

### 3.1 字体选择

- **数字/大标题**（KPI 数值、统计读数、英文技术标签）：**Rajdhani** 600/700 —— 窄体科技感，大屏经典。
  `https://fonts.googleapis.com/css2?family=Rajdhani:wght@400;500;600;700&display=swap`
- **中文正文**：系统栈 `"PingFang SC", "Microsoft YaHei", "Noto Sans SC", sans-serif`（中文不自引 Web 字体，控制体积）。
- **等宽**（坐标、ID、日志、测量读数）：`"Roboto Mono", "Fira Code", monospace`。

### 3.2 字号阶梯

`12 / 14 / 16 / 20 / 24 / 32 / 40`；KPI 数值可放大到 `48–64`。
- 正文最小 12px；大屏远距离观看优先 14px+。
- 所有数值用 `font-variant-numeric: tabular-nums;` 保证对齐跳动最小。
- 大屏字号相对桌面放大一档（观众在 3m 外观看），表格/面板正文 12–14px 是可接受底线。

## 四、间距、密度与圆角

- **密度**：紧凑。基础间距 `8 / 12 / 16 / 24 / 32`，面板内 padding `12–16px`，卡片 gap `8–12px`。
- **栅格**：大屏 24 列栅格，中央三维场景占 ≥2/3 宽，左右面板各 `300–360px`。
- **圆角**：`4px`（控件）`/ 8px`（卡片）`/ 0px`（大屏主面板边角装饰）。**禁止** 16–24px 大圆角（有机风，与科技硬边冲突）。
- **线宽**：HUD 装饰线一律 1px。

---

## 五、效果与动效

- **面板**：半透明玻璃 `background: rgba(14,18,35,0.85); backdrop-filter: blur(12px);` + 1px 边框 + 顶部 1px 高光 `rgba(255,255,255,0.08)`。
- **微光（克制）**：仅 KPI 大数字、选中态使用 `text-shadow: 0 0 8px rgba(249,115,22,0.45)`。不做全屏辉光。
- **三维场景内**：选中/高亮描边用科技青 `#22D3EE`；场景内健康着色用绿/琥珀/红点。
- **动效时长**：150–250ms，`ease`；面板淡入 + 4px 上移；大屏模块加载 stagger `60ms`。
- **铁律**：尊重 `prefers-reduced-motion`（直接渲染终态）；常驻大屏避免每帧动画、避免频繁闪烁；`cursor-pointer` 覆盖所有可点击元素。

## 六、布局骨架（三维大屏总览）

```
┌─────────── TopBar 56px ────────────┐  logo + 系统标题 | 时间/天气 | 模块切换
├─────────────┬─────────────────────┬─────────────┤
│ 左面板 320px │   中央 Cesium 三维场景   │ 右面板 320px │
│ 图层管理     │     （≥2/3 宽，全高）     │ 健康统计 KPI │
│ 工具箱       │                        │ 施肥建议      │
├─────────────┴─────────────────────┴─────────────┤
└─────────── OrchardControlBar 底栏 48px ───────────┘  透明度/显隐/精模懒加载
```

- 顶栏：模块切换（总览/诊断/查询/上传/施肥/图层/测量），激活态橙色下划线或胶囊；触控目标 ≥48px。
- 侧面板：标题 `14px/600` + 右上工具图标；内容区 `12–14px`，单列、可滚动，悬停淡入关闭按钮。
- 底栏：工具状态 + 控制项，按钮高度 ≥36px（触屏场景 ≥44px）。

## 七、组件级规则（Element Plus 定制）

- **按钮**：主按钮 = 橙底 `#F97316` + 深字 `#0F172A`；次按钮 = outline（`--border`）；危险 = `#EF4444`。高 32px（常规）/ 36–40px（大屏）。点击反馈 150ms。
- **输入框/下拉**：底 `#0B0F1F`，边框 `#334155`，focus 环用 `--accent` 或 `--tech`（2px）。
- **表格**：行高 36px，透明斑马纹，sticky 表头；健康状态列 = 色点 + 文字。
- **弹窗**：居中，宽 `480–720px`，玻璃底，顶部标题条，遮罩 `rgba(2,6,23,0.6)`；支持 ESC 关闭 + focus trap。
- **异步/加载**（TIF 上传、AI 推理）：
  - 上传按钮 loading 态并禁用（防重复提交）。
  - 任务进行中：进度条 + 步骤指示（如「推理中 3/4」），轮询任务状态时显示进度百分比与已识别株数。
  - 查询加载用骨架屏，不用空白屏。
- **测量工具**：读数用等宽字体，单位统一 `m / m² / m³`，结果区可复制。

## 八、图表（ECharts 深色主题）

- **默认调色板**：`['#F97316', '#22D3EE', '#22C55E', '#F59E0B', '#EF4444', '#38BDF8', '#A78BFA']`。
- **轴线/网格**：`axisLine: #334155`，`splitLine: rgba(148,163,184,0.15)`，`axisLabel: #94A3B8`。
- **健康/施肥分布**：绿–琥珀–红三段语义色，必须带图例 + 分段标签，不用纯色传达。
- **实时流**（如进度/实时监控）：流式面积图，当前值脉冲色 + 历史淡色，提供 pause/resume；<1 次/min 的数据用周期性折线即可，勿做假实时。
- **KPI 达标对比**：3–10 个 KPI 并排用 bullet/progress 更省空间，优于多个大仪表盘。
- **空间分布**（果树健康）：直接落 Cesium 场景点色 + 图例计数；图例用「色点 + 文字」，不依赖颜色单一信道。
- **图例与 tooltip 必备**；所有图表提供 hover 显示数值。

## 九、无障碍清单（交付前）

- [ ] 正文对比 ≥4.5:1，大字 ≥3:1（对照 2.4）。
- [ ] 全键盘可操作，focus 可见（橙 2px ring）。
- [ ] `prefers-reduced-motion` 生效。
- [ ] 图标用 SVG（Lucide/Heroicons/Element Plus icons），**禁用 emoji 当图标**。
- [ ] 语义状态 = 色点 + 文字/形状（不全靠颜色）。
- [ ] 触控目标：鼠标 ≥32px，触屏 ≥44px。
- [ ] 悬停有过渡（150–300ms）与清晰 hover 态。
- [ ] 断点验证：`1440 / 1920 / 2560`（大屏）；窄屏降级为面板叠层而非横向滚动。

## 十、反模式（避免）

- 全屏 Neon/扫描线/闪屏 → 阅读负担与性能成本。
- 大圆角（16–24px）有机风格 → 与科技硬边冲突。
- 只靠颜色传达健康/施肥状态。
- 橙底白字（对比不足）。
- 数据不足 12px 正文 / 灰底灰字。
- 组件混用随机 hex，必须走上方 token。
- 每帧动效 / 无视 `prefers-reduced-motion`。
